MyCryptoFinance (MCF) ​Web3-проект для обучения и развлечения. ​Содержит контракты для минта токена MCF (ERC-20) и NFT коллекции (ERC-721/1155). ​Цель: Изучение Web3-технологий. Важно: Токен и NFT не имеют реальной ценности. Проект чисто образовательный.
