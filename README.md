MyCryptoFinance (MCF)
​Web3-проект для обучения и развлечения.

Проект​ содержит Смарт контракты для минта токена MCF (ERC-20) и NFT коллекции (ERC-721/1155). ​
Цель: Изучение Web3-технологий.

❗️Важно: Токен и NFT развёрнуты в тестовой сети Sepolia и не имеют реальной ценности. Проект чисто образовательный.
